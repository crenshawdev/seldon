### What breaks

    If a `/seldon prd` rerun stops to ask the user a question, the turn that carries the answer can't update prd.md. That turn arrives through the "PRD questions answered" route, and §13's guard lets only two routes change a PRD that's already there. The answer turn is neither of them, so the user's answers are dropped, prd.md stays stale against the edited brief, and the turn ends on the later-release line.

    Updating an existing PRD when the brief changes is the whole point of the rerun this diff adds. In the branch where the rerun asks a question, the user gets no update at all. They also get a misleading message about spine and epics coming in a later release, and nothing tells them to run `/seldon prd` again.
